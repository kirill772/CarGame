# Neon Rush: Turbo Racers

Браузерная аркадная гонка (top-down с перспективой) на **HTML5 Canvas + vanilla JS (ES6 modules)**.

## Запуск

1. Открой папку:
   `Desktop/NeedForSpeed 10.0/neon-rush-turbo-racers/`
2. Дважды кликни `index.html`.

Игра запускается без сборки и без сервера.

## Управление

- Клавиатура:
  - WASD / Стрелки: газ/тормоз/поворот
  - Shift: нитро
  - Ctrl: дрифт
  - Space: пауза
- Мобильные устройства:
  - Виртуальный джойстик слева
  - Кнопки Nitro/Brake справа
- Геймпад:
  - Левый стик: поворот
  - RT/правый стик вверх: газ
  - LT/правый стик вниз: тормоз
  - A/B: нитро
  - LB/RB: дрифт

## Прогресс

Весь прогресс хранится в `localStorage` (JSON):
- Neon Coins
- Купленные машины
- Апгрейды
- Достижения и миссии дня
- Настройки

## Ассеты (assets/)

По ТЗ **машины рисуются только Canvas-ом**, без внешних картинок.

Если хочешь добавить свои файлы:

### Звуки
Сейчас игра использует **Web Audio API осцилляторы** (двигатель/дрифт/взрывы/бипы) и умеет
подхватывать локальные файлы из `assets/` (если ты их добавишь).

Можно добавить:
- `assets/music/menu.mp3`
- `assets/music/race.mp3`
- `assets/sfx/crash.wav`
- `assets/sfx/nitro.wav`

Важно: при открытии `index.html` напрямую браузер может ограничивать загрузку по сети (CORS). Поэтому
лучший вариант — держать ассеты **локально** в проекте и использовать свои/CC0 звуки.

Рекомендация: подключать музыку через `<audio>` в `index.html` или загружать `AudioBuffer` внутри `AudioManager`.

### Изображения
Не требуются. Можно добавить логотип/фон для UI (не для машин), если захочешь.

## Структура проекта

Смотри папки `css/`, `js/` и подкаталоги `classes/`, `world/`, `managers/`, `data/`.
